
Base theme from [docs.emulsify.info](https://emulsify.info/docs) which integrated [Storybook](https://storybook.js.org/)

![Emulsify Design System](https://github.com/emulsify-ds/.github/blob/6bd435be881bd820bddfa05d88905efe29176a0a/assets/images/header.png)

## Install package
Run `npm install`

## Development
1. Run `npm run develop` then building components style on storybook.
2. Run `npm run build` which will rebuild `disk` folder include files css, js, icon.svg, ... for theme.
3. Run `npm run storybook-build` which will rebuild static storybook folder `out`.
